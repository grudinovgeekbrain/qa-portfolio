# Функциональные тест-кейсы — интернет-магазин

**Объект:** `web-testing/online_market.html`  
**Статус набора:** подготовлен; выполнение нужно записать отдельно.

## TC-WEB-001 — Поиск товара по части названия

**Приоритет:** High  
**Предусловия:** Каталог успешно загружен.

**Шаги:**
1. Ввести в поле поиска часть названия одного из отображаемых товаров.
2. Проверить список карточек.

**Ожидаемый результат:** В списке остаются только товары, названия которых содержат введённую строку без учёта регистра.

## TC-WEB-002 — Поиск без совпадений

**Приоритет:** Medium  
**Предусловия:** Каталог успешно загружен.

**Шаги:**
1. Ввести строку, которой заведомо нет в названиях товаров, например `no-such-product-987`.
2. Проверить область каталога.

**Ожидаемый результат:** Карточки не отображаются. Желательно наличие понятного сообщения о том, что товары не найдены; если сообщения нет, зафиксировать UX-наблюдение.

## TC-WEB-003 — Сортировка по возрастанию цены

**Приоритет:** High  
**Предусловия:** Каталог успешно загружен.

**Шаги:**
1. В селекте сортировки выбрать «Сначала дешевые».
2. Сравнить цены в начале и конце списка.

**Ожидаемый результат:** Цены упорядочены от меньшей к большей.

## TC-WEB-004 — Сброс фильтров

**Приоритет:** Medium  
**Предусловия:** Введён поисковый запрос и выбрана сортировка.

**Шаги:**
1. Нажать «Сбросить фильтры».
2. Проверить значение поля поиска и селекта.
3. Проверить каталог.

**Ожидаемый результат:** Поиск очищен, значение сортировки возвращено к «По умолчанию», каталог отображает исходный набор товаров в порядке по умолчанию.

## TC-WEB-005 — Добавление товара в корзину

**Приоритет:** High  
**Предусловия:** Каталог загружен, корзина открыта.

**Шаги:**
1. Нажать «Добавить в корзину» у товара.
2. Проверить содержимое корзины, количество и итоговую стоимость.

**Ожидаемый результат:** В корзине появляется выбранный товар, количество равно 1, итоговая стоимость равна цене товара.

## TC-WEB-006 — Повторное добавление того же товара

**Приоритет:** High  
**Предусловия:** В корзине уже есть выбранный товар с количеством 1.

**Шаги:**
1. Повторно нажать «Добавить в корзину» у того же товара.
2. Проверить количество и сумму.

**Ожидаемый результат:** В корзине остаётся одна позиция данного товара; количество увеличивается до 2, стоимость позиции пересчитывается.

## TC-WEB-007 — Сохранение корзины после перезагрузки

**Приоритет:** Medium  
**Предусловия:** В корзине есть хотя бы один товар.

**Шаги:**
1. Запомнить состав и количество корзины.
2. Перезагрузить страницу.
3. После загрузки каталога проверить корзину.

**Ожидаемый результат:** Состав корзины и количество товаров восстанавливаются из `localStorage`.

## TC-WEB-008 — Длинное название товара на карточке

**Приоритет:** Medium  
**Предусловия:** В каталоге есть товар с длинным названием.

**Шаги:**
1. Найти карточку с длинным названием.
2. Проверить, можно ли прочитать название полностью.

**Ожидаемый результат:** Название полностью читаемо либо предусмотрено понятное поведение усечения, не скрывающее важную информацию. Зафиксировать фактический результат и, если есть дефект, создать ссылку на BUG-003.

## Результаты выполнения

Все тест-кейсы в этом файле имеют статус `Not run`, пока исполнитель не проведёт проверки и не зафиксирует фактический результат. Не указывайте `Passed` заранее.
