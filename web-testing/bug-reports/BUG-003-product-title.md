# BUG-003 — Название товара обрезается в карточке

## Окружение
- Браузер: Chrome
- Устройство: мобильное разрешение
- Разрешение: 345 × 724
- Среда: DevTools Device Toolbar
- Страница: online_market.html

## Предусловия
Открыть интернет-магазин в мобильном режиме.

## Шаги воспроизведения
1. Открыть страницу интернет-магазина.
2. Переключить DevTools в мобильный режим.
3. Найти товар с длинным названием.
4. Обратить внимание на отображение названия товара в карточке.

## Ожидаемый результат
Название товара полностью отображается в карточке либо корректно ограничивается без потери важной информации.

## Фактический результат
Высоты карточки недостаточно для полного отображения длинного названия товара. Часть текста обрезается.
