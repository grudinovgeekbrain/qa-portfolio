# BUG-004 — В HTML отсутствует meta viewport

## Окружение
- Браузер: Chrome
- Страница: `web-testing/online_market.html`
- Проверяемое разрешение: 345 × 724 в DevTools Device Toolbar

## Предусловия
Открыть страницу в мобильном режиме.

## Шаги воспроизведения
1. Открыть исходный HTML или DevTools Elements.
2. Проверить содержимое секции `<head>`.
3. Убедиться, что тег `<meta name="viewport" content="width=device-width, initial-scale=1.0">` отсутствует.
4. Проверить в мобильном эмуляторе, соответствует ли layout viewport ширине устройства и читаем ли интерфейс без непредусмотренного масштабирования.

## Ожидаемый результат
Страница задаёт viewport для ширины устройства и корректно отображается на мобильном экране.

## Фактические данные
В текущем исходном HTML есть `meta charset`, но `meta viewport` отсутствует. Визуальное последствие необходимо проверить в браузере и зафиксировать скриншотом.

- Priority: Medium после подтверждения визуального влияния
