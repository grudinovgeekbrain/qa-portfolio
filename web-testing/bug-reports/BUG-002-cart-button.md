# BUG-002 — Кнопка «Добавить в корзину» растягивается на всю ширину при одном результате поиска

## Окружение
- Браузер: Chrome
- Устройство: мобильное разрешение
- Разрешение: 345 × 724
- Среда: DevTools Device Toolbar
- Страница: online_market.html

## Предусловия
Открыть интернет-магазин в мобильном режиме.

## Шаги воспроизведения
1. Открыть страницу интернет-магазина.
2. Ввести в поле поиска запрос, по которому остаётся только один товар.
3. Найти карточку найденного товара.
4. Обратить внимание на кнопку «Добавить в корзину».

## Ожидаемый результат
Кнопка «Добавить в корзину» должна иметь аккуратную ширину и соответствовать размерам карточки товара.

## Фактический результат
При отображении одной карточки товара кнопка «Добавить в корзину» растягивается на всю ширину адаптивного блока.
