# BUG-002 — Кнопка «Добавить в корзину» растягивается на всю доступную ширину

## Исходное наблюдение
В исходной версии отчёта утверждалось, что кнопка растягивается при поиске, когда остаётся один товар.

## Результат триажа
В CSS приложения задано правило `.product button { width: 100%; }`. Оно распространяется на кнопки всех карточек и само по себе объясняет растягивание кнопки на доступную ширину. В коде не найдено отдельного условия, которое меняло бы ширину кнопки при одном результате поиска. Поэтому заявленная связь с поиском пока не подтверждена.

## Решение
`Closed — Not a confirmed defect`.

Чтобы открыть отчёт снова, необходимо получить требования или макет с целевой шириной кнопки и воспроизвести отличие от этих требований. Не следует считать ожидаемое поведение дефектом только потому, что элемент занимает всю ширину карточки.
