# BUG-001 — Селект сортировки плохо адаптирован под мобильные устройства

## Окружение
- Браузер: Chrome
- Устройство: мобильное разрешение
- Разрешение: 345 × 724
- Среда: DevTools Device Toolbar
- Страница: online_market.html

## Предусловия
Открыть интернет-магазин в мобильном режиме.

## Шаги воспроизведения
1. Открыть страницу интернет-магазина.
2. Переключить DevTools в мобильный режим.
3. Открыть селект сортировки товаров.
4. Оценить размеры и расположение выпадающего списка.

## Ожидаемый результат
Селект сортировки и его выпадающий список должны корректно отображаться на мобильном экране и не занимать чрезмерное пространство.

## Фактический результат
Выпадающий список сортировки выглядит громоздким и занимает значительную часть мобильного экрана, что ухудшает визуальное восприятие интерфейса.
