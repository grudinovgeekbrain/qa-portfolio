# QA Portfolio — Web и API Testing

Учебный проект для демонстрации базовых навыков тестирования веб-приложений и REST API.

## О проекте

В репозитории находится небольшой демонстрационный интернет-магазин. Он загружает каталог из Fake Store API и позволяет искать и сортировать товары, добавлять их в корзину и менять количество товаров в корзине.

**Моя задача как QA:** определить основные пользовательские сценарии, составить тестовую документацию, проверить поведение приложения и API, описать обнаруженные дефекты и зафиксировать результаты выполнения проверок.

> Это учебный проект. В текущей версии нет автоматизированного набора Playwright-тестов. Статусы выполнения тестов указаны только там, где есть зафиксированные результаты; непроверенные сценарии помечены отдельно.

## Объект и область тестирования

### Веб-приложение

- загрузка списка товаров;
- поиск по названию товара;
- сортировка по цене;
- сброс поиска и сортировки;
- добавление товара в корзину;
- изменение количества товара, удаление позиции и очистка корзины;
- сохранение корзины в `localStorage`;
- отображение интерфейса на узком экране;
- обработка ошибки загрузки каталога.

### API

- `GET https://fakestoreapi.com/products` — получение списка товаров;
- `POST https://fakestoreapi.com/products` — проверка структуры запроса и ответа при создании тестового товара.

Fake Store API используется как демонстрационный сервис. Операции записи в таком учебном API не следует считать подтверждением сохранения данных в реальном каталоге.

## Технологии и инструменты

- **Тестирование:** функциональное, smoke, регрессионные проверки, проверка адаптивности;
- **API:** HTTP, REST, JSON, Postman;
- **Веб:** HTML, CSS, JavaScript, DOM, Chrome DevTools;
- **Документация:** тест-кейсы, чек-лист, баг-репорты;
- **Контроль версий:** Git, GitHub.

## Как запустить демо-магазин

1. Скачайте или клонируйте репозиторий.
2. Откройте терминал в корневой папке `qa-portfolio`.
3. Запустите локальный статический сервер.

Windows:

```bash
py -m http.server 8000
```

macOS / Linux:

```bash
python3 -m http.server 8000
```

4. Откройте в браузере `http://localhost:8000/web-testing/online_market.html`.
5. Убедитесь, что интернет доступен: список товаров загружается с внешнего API.

Для проверки используйте Chrome DevTools → Device Toolbar и задайте, например, ширину экрана 345 px.

## Текущий статус

- Демонстрационное приложение и тестовые артефакты подготовлены для учебной практики.
- API-001 в исходной версии был помечен как Passed, но ответ запроса или скриншот не приложен; перед использованием результата в интервью тест следует повторить и зафиксировать.
- API-002 оформлен как сценарий для выполнения; результат пока не зафиксирован.
- BUG-003 связан с фиксированной высотой заголовка и `overflow: hidden` в исходном CSS.
- BUG-002 был пересмотрен: ширина кнопки `100%` сама по себе не доказывает дефект; текущая запись содержит результат триажа.
- BUG-001 является UI/UX-наблюдением и требует критерия дизайна, чтобы считать его подтверждённым дефектом.
- BUG-004 отмечает отсутствие `meta viewport`; поведение нужно дополнительно воспроизвести в мобильном режиме браузера.

## Принцип достоверности

Не отмечайте тест как **Passed**, пока не выполнен шаг проверки. Фиксируйте среду, фактический результат и доказательство (например, скриншот, response body или коллекцию Postman). Для дефекта указывайте шаги воспроизведения, ожидаемый и фактический результат, severity/priority и статус.
