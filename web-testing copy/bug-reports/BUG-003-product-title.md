# BUG-003 — Длинное название товара обрезается в карточке

## Окружение
- Браузер: Chrome
- Страница: `web-testing/online_market.html`
- Для мобильной проверки: DevTools Device Toolbar, ширина 345 px

## Предусловия
Каталог успешно загружен; есть товар с длинным названием.

## Шаги воспроизведения
1. Открыть интернет-магазин.
2. Найти карточку с длинным названием товара.
3. Проверить, полностью ли читается название.

## Ожидаемый результат
Название полностью читаемо либо усечение явно предусмотрено дизайном и не скрывает важную информацию.

## Фактические данные
В исходном CSS для `.product h3` указаны `height: 40px` и `overflow: hidden`. При названии, которое не помещается в выделенную высоту, часть текста может быть скрыта.

## Доказательства
В текущей версии приложен анализ исходного CSS, но нет скриншота выполнения в браузере. Для полного подтверждения приложить скриншот карточки с длинным названием.

## Severity / Priority
- Severity: Minor
- Priority: Low

## Status
`Needs visual confirmation` — причина видна в исходном CSS; приложите доказательство воспроизведения в браузере.
