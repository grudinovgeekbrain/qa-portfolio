# BUG-001 — UX-наблюдение: селект сортировки занимает заметное место на мобильном экране

## Окружение
- Браузер: Chrome
- Режим: DevTools Device Toolbar
- Разрешение: 345 × 724
- Страница: `web-testing/online_market.html`

## Предусловия
Открыть страницу в мобильном режиме после загрузки каталога.

## Шаги
1. Установить ширину эмуляции 345 px.
2. Найти селект сортировки.
3. Открыть выпадающий список и оценить доступность остальных элементов.

## Ожидаемый результат
Элементы управления остаются удобными для использования на мобильном экране. Конкретные требования к высоте и оформлению селекта должны быть заданы дизайном или требованиями продукта.

## Фактический результат по исходному наблюдению
Автор отметил, что выпадающий список визуально занимает значительную часть экрана. В текущей версии нет приложенного скриншота или утверждённого дизайн-критерия, поэтому наблюдение требует повторной проверки.

## Severity / Priority
- Severity: Не определена без подтверждения влияния на использование
- Priority: Low до подтверждения требований

## Status
`Needs confirmation` — рассматривать как UX-наблюдение, а не подтверждённый дефект.
