# Smoke-чек-лист — интернет-магазин

**Объект:** `web-testing/online_market.html`  
**Среда:** Chrome; локальный статический сервер; доступ к интернету для загрузки каталога  
**Статус:** сценарии нужно выполнить и отметить результат после проверки.

| ID | Проверка | Ожидаемый результат | Результат |
|---|---|---|---|
| SM-001 | Открыть страницу | Страница открывается без сломанной разметки | Not run |
| SM-002 | Загрузка каталога | Карточки товаров отображаются после ответа API | Not run |
| SM-003 | Поиск по части названия | Остаются товары, название которых содержит запрос | Not run |
| SM-004 | Поиск без совпадений | Список товаров пуст; пользователь понимает, что совпадений нет | Not run |
| SM-005 | Сброс поиска | Поле поиска очищается, каталог восстанавливается | Not run |
| SM-006 | Сортировка по возрастанию цены | Цены отображаются от меньшей к большей | Not run |
| SM-007 | Сортировка по убыванию цены | Цены отображаются от большей к меньшей | Not run |
| SM-008 | Сброс сортировки | Возвращается порядок по умолчанию | Not run |
| SM-009 | Добавить товар в корзину | Товар отображается в корзине с количеством 1 | Not run |
| SM-010 | Добавить тот же товар повторно | Количество товара увеличивается | Not run |
| SM-011 | Уменьшить количество | Количество уменьшается; при нуле позиция удаляется | Not run |
| SM-012 | Удалить позицию | Выбранная позиция исчезает из корзины | Not run |
| SM-013 | Очистить корзину | Корзина становится пустой | Not run |
| SM-014 | Перезагрузить страницу после добавления товара | Содержимое корзины сохраняется | Not run |
| SM-015 | Открыть страницу на ширине 345 px | Контент остаётся доступным и не требует непредусмотренного горизонтального скролла | Not run |
| SM-016 | Отключить интернет или заблокировать API | Отображается понятное сообщение об ошибке и действие повтора | Not run |

## Как фиксировать результат

Для каждой проверки заменить `Not run` на `Passed`, `Failed` или `Blocked` только после выполнения. Для `Failed` создать баг-репорт и приложить скриншот или другие доказательства.
