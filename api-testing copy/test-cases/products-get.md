# API-001 — Получение списка товаров

**Тип:** позитивный API-тест-кейс  
**Метод:** `GET`  
**Endpoint:** `https://fakestoreapi.com/products`  
**Приоритет:** High

## Цель

Проверить успешное получение списка товаров и соответствие JSON-ответа ожидаемой структуре.

## Предусловия

- Есть подключение к интернету.
- API доступен.
- Запрос выполняется через Postman или другой HTTP-клиент.

## Шаги и ожидаемый результат

1. Создать GET-запрос к endpoint выше.
2. Отправить запрос.
3. Проверить HTTP-статус: ожидается `200 OK`.
4. Проверить `Content-Type`: ответ должен быть JSON.
5. Проверить, что тело ответа является массивом.
6. Проверить, что для каждого элемента присутствуют поля `id`, `title`, `price`, `description`, `category` и `image`.
7. Проверить типы полей: `id` — число, `title` — строка, `price` — число, остальные перечисленные текстовые поля — строки.
8. Проверить, что массив не пустой и ответ можно разобрать как JSON.
